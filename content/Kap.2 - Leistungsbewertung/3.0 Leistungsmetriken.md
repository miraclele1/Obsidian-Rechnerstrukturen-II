## Leistungsmetriken:
- Taktfrequenz
- Laufzeitmessung
- Perfomanz
	- Workloads
- Programmabhängiges Leistungsmodell
- Speicherbandbreite (пропускная способность)

### Taktfrequenz:
Wie viel Operationen CPU pro Sekunde durchführen kann, in Hz gemessen. (Anzahl)

$$T_{CLK} = \frac{1}{f_{CLK}}$$
### Laufzeitmessung
$$t_{ex}(A, P, I)$$
A - Machine (Architecture), P - Program, I -Input, t{ex} - execution time
***Machine von Programm unter Input***
*Это время выполнения конкретной **Программы** с определенным **Вводом** на определенной **Машине**.*


### Performanz  (Leistungsfähigkeit)
$$p_{(A, P, I)} = \frac{1}{t_{ex}(A,P,I)}$$![[Pasted image 20260412181631.png|396]]

Рейтинг ПК может быть разным - одна и та же машина может быть лидером для одного профиля  и аутсайдером для другого. w(k,i) - k=профиль, i=прога

###### Normalisierte Performanz
Сравнение с очень популярным предшественником.  Просто называют "мой  быстрее  XXX в 2.5 раза". Одна понятная всем шкала.

**SPEC тесты** - популярный список программ(компиляторы, симуляторы) для тестов.
