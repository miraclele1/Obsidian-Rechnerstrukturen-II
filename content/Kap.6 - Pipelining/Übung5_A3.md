**а) Hazards и их расположение**

В процессоре с 5-стадийным конвейером (без Forwarding и Hazard Detection) запись в регистр происходит на стадии **WB** (5-й такт), а чтение — на стадии **ID** (2-й такт). При допущении, что запись происходит в первой половине такта, а чтение во второй, между связанными инструкциями требуется дистанция в 2 такта (то есть **2 NOP**). Решения о ветвлении принимаются на стадии **EX**, что означает выборку двух лишних инструкций до применения адреса перехода (требуется **2 NOP** после каждого ветвления).

- **Data Hazards (RAW - Read After Write):**
    
    1. Зависимость по регистру `t0`: между `lw t0, 0(a0)` и `slt t1, s0, t0`.
        
    2. Зависимость по регистру `t1`: между `slt t1, s0, t0` и `beq t1, zero, l1`.
        
    3. Зависимость по регистру `a1`: между `addi a1, a1, -1` и `bne a1, zero, loop`.
        
- **Control Hazards (Конфликты управления):**
    
    1. Ветвление `beq t1, zero, l1`.
        
    2. Ветвление `bne a1, zero, loop`.
        
    3. Безусловный переход `j end`.

**б) Код с добавлением минимального количества NOP**

Фрагмент кода

```
.text
addi a0, gp, 0
addi a1, zero, 5
loop:
  lw t0, 0(a0)
  nop                 # Ожидание RAW для t0 (такт 1)
  nop                 # Ожидание RAW для t0 (такт 2)
  slt t1, s0, t0
  nop                 # Ожидание RAW для t1 (такт 1)
  nop                 # Ожидание RAW для t1 (такт 2)
  beq t1, zero, l1
  nop                 # Branch Delay Slot для beq
  nop                 # Branch Delay Slot для beq
  addi s0, t0, 0
l1:
  addi a0, a0, 4
  addi a1, a1, -1
  nop                 # Ожидание RAW для a1 (такт 1)
  nop                 # Ожидание RAW для a1 (такт 2)
  bne a1, zero, loop
  nop                 # Branch Delay Slot для bne
  nop                 # Branch Delay Slot для bne
end:
  j end
  nop                 # Branch Delay Slot для j
  nop                 # Branch Delay Slot для j
```

**в) Уменьшение количества NOP путем переупорядочивания**

Количество `nop` можно сократить с помощью техники **Instruction Scheduling** (переупорядочивание инструкций). Независимые инструкции, такие как `addi a0, a0, 4` и `addi a1, a1, -1`, можно переместить с их текущих позиций:

1. **Заполнение Data Hazards:** Поместить их сразу после `lw t0, 0(a0)`, чтобы выполнить полезную работу вместо пустых тактов ожидания `t0`.
    
2. **Заполнение Branch Delay Slots:** Использовать слоты после инструкций ветвления (`beq`, `bne`) для выполнения операций, которые должны отработать в любом случае (независимо от того, произойдет прыжок или нет).
