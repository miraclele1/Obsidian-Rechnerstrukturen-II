### Внутренние ссылки

- **Ссылка со своим текстом:** `[[Имя заметки|Отображаемый текст]]`
- **Ссылка на заголовок:** `[[Имя заметки#Название заголовка]]`
- **Ссылка на конкретный блок (абзац):** `[[Имя заметки#^идентификатор]]`
    
    - _Как сделать:_ В исходной заметке введите `[[Имя заметки^`. Выберите нужный абзац из списка — Obsidian автоматически сгенерирует случайный код блока (например, `^1a2b3c`) и свяжет его.
        

### Блоки выносок (Callouts)

Синтаксис: `> [!тип] Заголовок` (текст на следующей строке с отступом `>`).
- **Свернут по умолчанию:** `> [!info]- Заголовок`
- **Развернут по умолчанию:** `> [!info]+ Заголовок`
### Встроенные типы выносок

| **Код ([!тип])**                  | **Цвет**     | **Иконка**           |
| --------------------------------- | ------------ | -------------------- |
| `note`, `seealso`                 | Синий        | Карандаш             |
| `info`, `todo`                    | Голубой      | Буква i / Чекбокс    |
| `tip`, `hint`, `important`        | Бирюзовый    | Огонь / Ключ         |
| `success`, `check`, `done`        | Зеленый      | Галочка              |
| `question`, `help`, `faq`         | Желтый       | Вопрос               |
| `warning`, `caution`, `attention` | Оранжевый    | Восклицательный знак |
| `failure`, `fail`, `missing`      | Красный      | Крестик              |
| `danger`, `error`                 | Ярко-красный | Молния               |
| `bug`                             | Малиновый    | Жук                  |
| `example`                         | Фиолетовый   | Список               |
| `quote`, `cite`                   | Серый        | Кавычки              |
> [!note]- Заголовок
> открыл

### Изменение цвета и значка (Кастомизация)

Нативно внутри одного блока изменить цвет «на лету» нельзя. Для создания своего типа выноски используется **CSS-сниппет** (Настройки -> Внешний вид -> CSS-сниппеты):

CSS

```
.callout[data-callout="my-type"] {
    --callout-color: 200, 50, 50; /* RGB цвет фона и рамки */
    --callout-icon: lucide-heart; /* Имя иконки из библиотеки Lucide */
}
```

После этого в заметке можно писать: `> [!my-type]`.
### Внедрение контента (Embeds / Transclusion)

Отображает содержимое другой заметки прямо в текущей.
- **Внедрить заметку целиком:** `![[Имя заметки]]`    
- **Внедрить только один раздел:** `![[Имя заметки#Заголовок]]`
- **Внедрить конкретный блок:** `![[Имя заметки#^идентификатор]]`
### Продвинутое форматирование текста

- **Выделение маркером:** ==текст==
- **Зачеркнутый текст:** `~~текст~~`
- **Комментарии (скрыты в режиме чтения):** `%%текст комментария%%`
- **Сноски:**
    - В тексте: `Текст заметки[^1]`
    - Внизу страницы: `[^1]: Текст описания сноски.`
    - Встроенная (инлайн) сноска: `^[Текст сноски прямо внутри строки]`

### Математика
**Режимы отображения:**

- Внутри строки: $E=mc^2$ (код: E=mc^2 в одиночных долларах)
    
- Выделенный блок по центру:
    
    $$E=mc^2$$
    
    (код: E=mc^2 в двойных долларах)
    

**Базовые операции:**

- Нижний индекс: $x_i$ (код: x_i)
    
- Верхний индекс: $x^2$ (код: x^2)
    
- Сложный индекс: $x_{i+1}$ (код: x_{i+1}), $e^{2x}$ (код: e^{2x})
    
- Дробь: $\frac{a}{b}$ (код: \frac{a}{b})
    
- Квадратный корень: $\sqrt{x}$ (код: \sqrt{x})
    
- Корень n-й степени: $\sqrt[n]{x}$ (код: \sqrt[n]{x})
    

**Знаки и символы:**

- Умножение: $\cdot$ (код: \cdot) или $\times$ (код: \times)
    
- Деление: $\div$ (код: \div)
    
- Приближенное равенство: $\approx$ (код: \approx)
    
- Не равно: $\neq$ (код: \neq)
    
- Меньше или равно: $\le$ (код: \le)
    
- Больше или равно: $\ge$ (код: \ge)
    

**Высшая математика:**

- Сумма: $\sum_{i=1}^{n}$ (код: \sum_{i=1}^{n})
    
- Интеграл: $\int_{a}^{b}$ (код: \int_{a}^{b})
    
- Предел: $\lim_{x \to \infty}$ (код: \lim_{x \to \infty})
    
- Вектор: $\vec{a}$ (код: \vec{a}) или $\overline{a}$ (код: \overline{a})
    
- Частная производная: $\frac{\partial f}{\partial x}$ (код: \frac{\partial f}{\partial x})
    

**Греческие буквы:**

- Строчные: $\alpha$ (\alpha), $\beta$ (\beta), $\gamma$ (\gamma), $\delta$ (\delta), $\pi$ (\pi), $\sigma$ (\sigma), $\omega$ (\omega)
    
- Заглавные: $\Gamma$ (\Gamma), $\Delta$ (\Delta), $\Pi$ (\Pi), $\Sigma$ (\Sigma), $\Omega$ (\Omega)
    

**Стрелки и логика:**

- Стрелка вправо: $\to$ (код: \to)
    
- Следование: $\implies$ (код: \implies)
    
- Эквивалентность: $\iff$ (код: \iff)
    
- Квантор всеобщности: $\forall$ (код: \forall)
    
- Квантор существования: $\exists$ (код: \exists)
