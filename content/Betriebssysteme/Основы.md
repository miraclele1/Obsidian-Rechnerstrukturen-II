```
int i = 5;

```
Через указатель быстрее чем с переменными.

Программы обращаются к железу через **системные вызовы**. (`open()`, `read()`, `write()`, ...)

### Вызов fork()
Создает полную копию процесса(ребёнок). Становится  два  идентичных процесса.
fork() у родителя - выдает ID ребенка
fork() у ребенка  - выдает 0.
У ребенка своя память - перемена у родителя не поменяется.

#### Пример с Probeklausur
```
int main() {
    int i = 1;
    while (i != 3) {
        fork();
        ++i;
        printf("Prozess Nummer: %d\n", i);
    }
}
```
fork() создает  идентичный процесс, при первой итерации Output:
"_Prozess Nummer: 2_
_Prozess Nummer: 2_"

Вторая итерация, снова fork(), уже 4 процесса. Все увеличивают **i** до 3. Цикл заканчивается.
Итоговый Output:
"_Prozess Nummer: 2_
_Prozess Nummer: 2_
_Prozess Nummer: 3_
_Prozess Nummer: 3_
_Prozess Nummer: 3_
_Prozess Nummer: 3_"

### Scheduling
Когда процессов много, а ядер мало, ОС решает какой процесс идет некст.

Два важных алгоритма: **RMS**(Rate-Monotonic Scheduling)  и **EDF**(Earliest Deadline First)
#### RMS
Rate-Monotonic Scheduling
Чем чаще(Periode) процесс должен повторяться, тем выше приоритет.
Динамический, постоянно пересчитывается.

Пример: А запускается каждые 4мс, Б каждые 8мс.
#### EDF
Earliest Deadline First
Выбирают того у кого дедлайн ближе всего. (срочность)
Пример: дедлайн у процесса Б через 2мс, а у А через 5мс. 
У процессов есть 2 значения - частота и срочность(Это запас времени до критического момента). Датчик дыма редко, но должен завершиться за 1мс, без задержек.
#### Другие алгоритмы
**FCFS** - First come first serve.
**Round  Robin(RR)**  - Каждому даётся кусочек времени, не успел -> в конец очереди.
**SPN** - shortest process next.

### Speicher Layout(Сегметы памяти)
речь про RAM.
![[Pasted image 20260608232128.png|351]]
Снизу вверх:
- **Text:** код программы. Эта область защищена от записи.
- **Data:** Хранит **инициализированные** *глобальные и статичные* переменные (например, `int x = 5;`).
- **BSS:** Хранит **неинициализированные** *глобальные и статичные* переменные. При запуске программы они автоматически заполняются нулями.
- **Heap (Куча):** Память для динамического выделения во время работы программы (через `malloc()` или `new`). Растет **вверх** (в сторону увеличения адресов).
	  Пояснение:
		  - Data & BSS статика, Heap динамика. Программа в рантайме запрашивает у ОС память если юзер загрузил например картинку.
		    ![[Pasted image 20260608232934.png]]
		  - `malloc()` и `new` это команды для запроса памяти в C++
		  - Благодаря Куче память расходуется гибко: открыл фото - RAM занялась, закрыл - освободилась.

- **Stack (Стек):** Хранит *локальные* переменные функций, параметры вызовов и адреса возврата. Растет **вниз** (навстречу куче). ^stackobsidian
