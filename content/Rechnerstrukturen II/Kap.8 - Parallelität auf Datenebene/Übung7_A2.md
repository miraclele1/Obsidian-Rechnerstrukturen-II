Цель — увидеть, как современный компилятор превращает обычный цикл в мощный векторный код.
![[Pasted image 20260516000125.png]]
## (a) Оптимизации

- **Без опций:** Компилятор выполняет «наивную» трансляцию кода. Каждое число из массива складывается по отдельности (скалярная обработка).
- **С опциями** **-O3 -march=skylake****: Включается **авто-векторизация** (SIMD — Single Instruction, Multiple Data). Компилятор распознает, что итерации цикла независимы, и переписывает код так, чтобы использовать векторные регистры и инструкции архитектуры Skylake (AVX2). Также часто применяется **развертывание цикла** (Loop Unrolling) для уменьшения накладных расходов на переходы.

## (b) x86-инструкции для сложения

- **До оптимизации:** Используется стандартная инструкция сложения целых чисел, например **add** (или `addq` для накопления 64-битной суммы).
- **После оптимизации:** Используются векторные инструкции набора AVX2. Основная рабочая инструкция — **vpaddw** (Vector Parallel Add Word). Буква `p` (parallel) означает работу с упакованными данными, а `w` (word) — работу с 16-битными словами.

##  (c) Ширина данных

- **До оптимизации:** Сложение происходит на ширине **16 бит** (размер одного элемента `uint16_t`). Процессор обрабатывает ровно одно число за операцию.
- **После оптимизации:** Сложение происходит на ширине **256 бит** (размер YMM-регистров в архитектуре Skylake). Поскольку каждое число занимает 16 бит, процессор складывает сразу **16 чисел за один такт** (256/16=16).

## **Итог:** 
Благодаря SIMD теоретическая скорость выполнения этой части программы возрастает в 16 раз.
