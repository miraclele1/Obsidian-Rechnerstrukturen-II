### Дано
**Правила выполнения:** Каждая команда выполняется независимо от других. Все инструкции используют исходные состояния регистров и памяти из таблицы. Синтаксис `add A, B` означает `A = A + B`.

**Исходные значения памяти (Адрес -> Значение):**
- [1000] -> 100
- [1100] -> 200
- [1200] -> 300
- [1600] -> 1100

### Решение
1. **`add R1, 200(R8)` — Базисная адресация со смещением** К значению базового регистра **R8** (1000) прибавляется смещение **200**. Формируется адрес памяти 1200. Из ячейки 1200 извлекается число 300. **Итог:** R1 = 0 + 300 = **300**.
    
2. **`add R3, @(1600)` — Косвенная адресация через память** Символ `@` указывает на косвенное обращение. Сначала читается значение по адресу **1600** (это 1100). Полученное число используется как новый адрес. Из ячейки **1100** извлекается число 200. **Итог:** R3 = 10 + 200 = **210**.
    
3. **`add R8, #100` — Непосредственная адресация** Символ `#` означает, что операнд является константой, а не адресом или регистром. К R8 просто прибавляется число 100. **Итог:** R8 = 1000 + 100 = **1100**.
    
4. **`add R7, R8` — Прямая регистровая адресация** Данные берутся напрямую из регистра-источника **R8** (1000). Обращений к памяти нет. **Итог:** R7 = 500 + 1000 = **1500**.
    
5. **`add R6, (R8)` — Косвенная регистровая адресация** Скобки `()` указывают, что значение регистра **R8** (1000) является адресом памяти. Из ячейки памяти **1000** извлекается число 100. **Итог:** R6 = 200 + 100 = **300**.
    
6. **`add R2, (1200)` — Прямая абсолютная адресация** Указан прямой адрес в памяти. Из ячейки **1200** извлекается число 300. **Итог:** R2 = 5 + 300 = **305**.

|**Команда**|**Режим адресации**|**Вычисление и изменение**|
|---|---|---|
|**add R1, 200(R8)**|Базисная со смещением (Registerrelativ)|**R1** = 0 + Mem[200 + 1000] = 0 + Mem[1200] = **300**|
|**add R3, @(1600)**|Косвенная через память (Indirekt)|**R3** = 10 + Mem[Mem[1600]] = 10 + Mem[1100] = 10 + 200 = **210**|
|**add R8, #100**|Непосредственная (Unmittelbar)|**R8** = 1000 + 100 = **1100**|
|**add R7, R8**|Прямая регистровая (Register)|**R7** = 500 + 1000 = **1500**|
|**add R6, (R8)**|Косвенная регистровая (Registerindirekt)|**R6** = 200 + Mem[1000] = 200 + 100 = **300**|
|**add R2, (1200)**|Прямая абсолютная (Direkt)|**R2** = 5 + Mem[1200] = 5 + 300 = **305**|
