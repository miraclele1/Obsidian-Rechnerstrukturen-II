# Дано
- Размер кода операции: (Oppcode) **$1$ байт
- Размер любого адреса памяти (указатель на переменную): **$2$ байта
- Размер данных(переменных): **$4$ байта.
- Длина любой инструкции должна быть кратна целому байту (если получается дробное число байт, округляем в большую сторону для выравнивания).
- Оптимизации запрещены. Это означает, что каждую строку высокоуровневого кода (например, `A = B + C`) мы переводим в машинный код изолированно, шаг за шагом, заново загружая переменные из памяти.

### Разбор архитектур (как они работают)

1. **Stack (Стек):** Все операции выполняются на верхушке стека. Для сложения нужно положить два значения в стек (`PUSH`), вызвать команду сложения (`ADD` — она сама возьмет два верхних значения и положит результат обратно) и забрать результат из стека (`POP`).
2. **Akkumulator (Аккумулятор):** Процессор имеет только один рабочий регистр. Команды работают с ним по умолчанию. `LOAD B` загрузит значение в аккумулятор, `ADD C` прибавит к нему значение из памяти, `STORE A` сохранит результат из аккумулятора в память.
3. **Register-Register (Регистровая):** Математика (`ADD`, `SUB`) происходит только внутри процессора между 16 регистрами. Для указания регистра нужно **$4$ бита** (т.к. $2^4 = 16$). Работа с памятью идет только через `LOAD` и `STORE`.
4. **Speicher-Speicher (Память-Память):** Команды работают напрямую с адресами в памяти. Инструкция `ADD A, B, C` берет значения по адресам B и C, складывает их и пишет по адресу A.

### Решение подзадач

#### (a) Реализация кода (Ассемблер)

_Дано:_ Написать код для двух последовательностей без оптимизаций.

**Sequenz 1:** `A = B + C;`

```
// Stack
PUSH B
PUSH C
ADD
POP A

// Akkumulator
LOAD B
ADD C
STORE A

// Register-Register
LOAD R1, B
LOAD R2, C
ADD R3, R1, R2
STORE R3, A

// Speicher-Speicher
ADD A, B, C
```

**Sequenz 2:** `A = B + C; B = A + C; D = A - B;`

_(Ввиду запрета на оптимизации переводим каждую строку отдельно)_
```
// Stack
PUSH B; PUSH C; ADD; POP A    // A = B + C
PUSH A; PUSH C; ADD; POP B    // B = A + C
PUSH A; PUSH B; SUB; POP D    // D = A - B

// Akkumulator
LOAD B; ADD C; STORE A
LOAD A; ADD C; STORE B
LOAD A; SUB B; STORE D

// Register-Register
LOAD R1, B; LOAD R2, C; ADD R3, R1, R2; STORE R3, A
LOAD R4, A; LOAD R5, C; ADD R6, R4, R5; STORE R6, B
LOAD R7, A; LOAD R8, B; SUB R9, R7, R8; STORE R9, D

// Speicher-Speicher
ADD A, B, C
ADD B, A, C
SUB D, A, B
```

### b)
_Дано:_ Посчитать, сколько байт занимает сам код (инструкции) для каждой архитектуры.

_Расчет размеров одной инструкции:_
- **Stack:** `PUSH/POP` = Опкод ($1$ байт) + Адрес ($2$ байта) = **$3$ байта**. `ADD/SUB` = только Опкод = **$1$ байт**.
- **Akkumulator:** Все команды имеют Опкод ($1$ байт) + Адрес ($2$ байта) = **$3$ байта**.
- **Register-Register:**
    - `LOAD/STORE reg, addr` = Опкод ($8$ бит) + Регистр ($4$ бита) + Адрес ($16$ бит) = $28$ бит. Выравниваем до целого байта $\rightarrow$ $32$ бита = **$4$ байта**.
    - `ADD/SUB r, r, r` = Опкод ($8$ бит) + 3 регистра ($12$ бит) = $20$ бит. Выравниваем $\rightarrow$ $24$ бита = **$3$ байта**.
- **Speicher-Speicher:** `ADD/SUB addr, addr, addr` = Опкод ($1$ байт) + 3 адреса ($6$ байт) = **$7$ байт**.
