# Цель задачи

Понять, как процессор структурирует память для быстрого поиска данных. Для этого нужно разбить адрес на функциональные части (**Tag**, **Index**, **Offset**) для трех разных уровней кэш-памяти (L1I, L1D, L2) исходя из их архитектурных характеристик.

## Дано

- **Размер адреса процессора:** 64 бита. Это размер ячейки в схеме, которую нужно заполнить.
- **Физический адрес:** Реально используются только 48 бит. Это означает, что верхние 16 бит (с 48 по 63) всегда остаются пустыми (зарезервированы или не используются).
- **Размер блока (Line Size):** Для всех кэшей составляет **64 Байта**.
- **Требуется:** Для каждой схемы a), b) и c) указать диапазоны битов для четырех зон: неиспользуемые биты, **Tag** (тег), **Index** (индекс) и **Offset** (смещение).
